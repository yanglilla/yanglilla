## 💻 프로젝트

### [KM · 계명종합중기 홈페이지](https://github.com/yanglilla-1/KM)

굴삭기·중장비 임대 서비스를 소개하는 **React 기반 반응형 웹사이트**입니다.

- 회사·보유 장비 소개, 위치 안내, 견적전화 및 외부 문의 채널 연결
- 모바일 화면 배치와 글자 크기, 메뉴·아이콘 등 UI/UX 개선
- **기술:** React · JavaScript · Material UI · Vite
- **공개 범위:** 포트폴리오용 현재 소스입니다. 실서버 구현을 위한 운영 원본과 과거 개발 기록은 별도 **비공개 프로젝트**에서 관리합니다.

[소스 보기](https://github.com/yanglilla-1/KM) · [회사 홈페이지](https://www.kmheavy.kr)

### [Egglab · Android 근태·업무 관리 UI](https://github.com/yanglilla/Android_Egglab)

근로자의 출퇴근과 업무 정보를 확인하는 **Java 기반 Android UI 프로토타입**입니다.

- 출퇴근 홈 화면과 업무 신청·스케줄·급여 메뉴 구성
- DrawerLayout·NavigationView를 이용한 사이드 메뉴 및 Fragment 전환
- **기술:** Java · Android XML · AndroidX · Material Components
- **구현 범위:** 화면 구성과 탐색 흐름을 구현했습니다. 기록 저장·근무시간 계산·서버 연동은 미구현 상태입니다.

[소스 보기](https://github.com/yanglilla/Android_Egglab) · [원본 프로젝트](https://github.com/rohgibong/Android_Egglab)
